📌 이걸 왜 해야 하나요?

고객이 saeloan.co.kr에서 상담 신청을 하면, 이메일로 알림이 와야 합니다.
지금은 이 기능이 꺼져 있어서 고객 신청을 놓칠 수 있습니다!

📋 따라하세요 (5분이면 됩니다)

  1. PC에서 vercel.com 접속 → 로그인

  4. 왼쪽 메뉴 Environment Variables 클릭
  5. 아래 3개를 하나씩 입력하세요:
SMTP_USER = 이메일주소@gmail.com SMTP_PASS = 구글앱비밀번호16자리 NOTIFY_EMAIL = hejunl@hanmail.net
💡 Gmail 앱 비밀번호 만드는 법: 구글 계정 → 보안 → 2단계인증 → 앱 비밀번호 → 새로만들기
  1. 3개 모두 입력 후 Save 클릭
  2. Vercel 화면 위쪽 Deployments → 최신 배포 → Redeploy 클릭
⚠️ 비밀번호는 절대 다른 사람에게 알려주지 마세요!
