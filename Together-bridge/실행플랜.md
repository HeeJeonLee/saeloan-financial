# Together-bridge 상세 실행 플랜

## 1. 준비 단계 (1주)
- 도메인 구입, Bubble.io/Notion으로 랜딩페이지 제작
- Google Sheets/Supabase로 파트너·실적 관리 시트 생성
- n8n/Google Apps Script로 자동화 기본 플로우 구축
- 카카오채널/텔레그램 챗봇 개설, AI API 연동

## 2. MVP 론칭 (2~3주)
- 파트너사(부동산, 병원, 학원 등) 50곳 리스트업
- 1차 영업 메시지 자동 발송, 회신 파트너 AI 챗봇 상담
- Bubble.io로 서비스 신청/매칭/예약 폼 구현
- 실적 집계/정산/리포트 자동화

## 3. 마케팅/고객 유입 (4~6주)
- AI 자동 콘텐츠 생성(블로그, SNS, 유튜브)
- 광고 예산 최소화, 무료 채널 우선 활용
- 후기/리뷰 자동 수집, 신뢰도 강화

## 4. 확장/고도화 (2~6개월)
- 파트너 300곳, 서비스 2,000건 목표
- 프리미엄/보험/금융 연계, 글로벌 진출 준비
- AI SaaS/API, 자동화 고도화, 인력 투입 단계적 확대
