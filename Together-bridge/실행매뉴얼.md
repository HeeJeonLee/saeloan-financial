# Together-bridge 상세 실행 매뉴얼

## 1. 준비
- 도메인 구입(가비아/카페24)
- Bubble.io/Notion으로 랜딩페이지 제작
- Google Sheets: 파트너/실적 관리 시트 생성
- Supabase: DB 연동(선택)
- n8n/Google Apps Script: 자동화 기본 플로우 구축
- 카카오채널/텔레그램 챗봇 개설, AI API 연동

## 2. 파트너사 영업
- 샘플 리스트 기반 1차 메시지 자동 발송(n8n/Apps Script)
- 회신 파트너는 AI 챗봇/자동화로 상담→계약서 자동 발송
- 실적/정산/리포트 자동화

## 3. 마케팅/고객 유입
- AI 자동 콘텐츠 생성(Claude/Gemini/Perplexity)
- SNS/블로그/유튜브 자동 발행(n8n/Apps Script)
- 후기/리뷰 자동 수집

## 4. 확장/고도화
- 파트너 300곳, 서비스 2,000건 목표
- 프리미엄/보험/금융 연계, 글로벌 진출 준비
- AI SaaS/API, 자동화 고도화, 인력 투입 단계적 확대
