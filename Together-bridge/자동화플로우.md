# Together-bridge AI 자동화 플로우

1. 고객/파트너 문의 → AI 챗봇(카카오/텔레그램)
2. AI 자동 상담/분류 → Google Sheets/Supabase 자동 등록
3. AI 매칭/배정 → 파트너 알림/실적 집계
4. 정산/계약/리포트 자동화
5. 고객/파트너 피드백 수집 → AI 실적 분석/리포트
6. 자동 광고/콘텐츠 생성 → SNS/유튜브/카카오 자동 발행
7. 성과 리포트 자동화

## n8n/Google Apps Script 예시 코드(파이프라인)
- 신규 문의 → Google Sheets row 추가
- Sheets row 추가 → 파트너사 이메일/카톡 자동 발송
- 실적 집계 → 월말 자동 리포트 생성 및 발송
- SNS/블로그/유튜브 콘텐츠 자동 생성 및 발행
